# Go Under Feature

## Description

A player in the game of Euchre can replace 3 cards in their hand if there are 3 or more cards below a Jack in rank.  The option is only available during the Kitty bidding round and only if the player has 3 or more cards of 9s and 10s.  The 3 cards that the player wants to replace are substituted by the 3 cards underneath the displayed kitty card.
